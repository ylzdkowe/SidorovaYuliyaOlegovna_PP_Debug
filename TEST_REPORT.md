# Отчёт о тестировании LibraryApp

## Объект тестирования
Консольное приложение для учёта книг в библиотеке. Реализованы классы Book и Library.

## Методика тестирования
Ручное тестирование, отладка (точки останова, пошаговое выполнение), статический анализ кода.
